Polarizer Images

Pre-made, packed OS images for polarizer — the EOF barrier around things. Each image ships a ready-to-boot qcow2 disk plus a manifest describing its ssh settings.

polarizer getimg openbsd:latest  

Available Images

Image Size SHA-256
openbsd:latest openbsd-latest.qcow2 latest.json

How to Use

  1. Point polarizer at this channel and pull the image:
    polarizer getimg openbsd:latest
  2. Staple a containment around it:
    polarizer contain containment-1
  3. Boot it and get the shell:
    polarizer run containment-1

You'll land on ssh -p 65531 with a [OpenBSD] $ prompt.

Images are pre-made by hand; verify the sha256 in each manifest before trusting a disk.
